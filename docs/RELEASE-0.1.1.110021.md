# SkysTerrainSmoother-BiomesOPlenty-Addon 0.1.1.110021

BOP grass and soil pieces now follow nearby snow, higher snowy terraces and
cold, exposed ground. The updated Grass Slabs, Building Pieces and Terrain
Smoother releases provide the matching snow behaviour across the stack.

Back up your world before updating. Install the main jar on the client and
server. Saved pieces retain their materials and orientations; new smoothing
applies only to newly generated chunks.
